# 序號管理（SerialManager）

管理遊戲抽獎序號的 Windows 小工具：記錄每組序號的內容、效期、有沒有兌換、送給了誰，快到期時會提醒。
資料只存在自己電腦上，不需要網路、不需要帳號。

## 下載與執行

1. 到 [Releases](https://github.com/georgeprima5/-SerialManager/releases) 下載最新版的 `SerialManager.exe`。
2. 把它放到一個**自己的資料夾**（例如 `D:\工具\序號管理\`），直接雙擊執行。不需要安裝，也不需要另外裝 .NET。

注意事項：

- **資料檔跟 exe 放在同一個資料夾**：第一次執行會在 exe 旁邊建立 `serials.db`，所有序號和設定都存在裡面。
  搬移或換電腦時，把 exe 和 `serials.db` 一起帶走；請不要放在 `C:\Program Files` 這類沒有寫入權限的位置。
- **第一次開啟可能出現「Windows 已保護您的電腦」**：因為這個 exe 沒有付費的程式碼簽章。
  點「其他資訊」→「仍要執行」即可，之後就不會再問。
- **需要 Microsoft Edge WebView2 Runtime**：Windows 11 內建；Windows 10 有安裝新版 Edge 通常也已經有了。
  如果打開是一片空白，請到微軟官網安裝「WebView2 Runtime」。
- 只能同時開一個；再點一次 exe 會把已經開著的視窗叫到前面。

系統需求：Windows 10 / 11（64 位元）。

## 功能

### 新增序號

- **手動新增**：填序號、內容、獎項等級、效期後按「新增」。效期會自動帶入上一次用的日期，方便連續輸入。
- **批次匯入**：把 Excel／Google 試算表的資料整塊複製，貼到「批次匯入」視窗，選好效期後按「匯入」。
  每一列用 Tab 分隔欄位，支援三種格式（可以混著貼）：

  | 欄數 | 欄位順序 |
  |---|---|
  | 4 欄 | 取得時間、獎項等級、內容、序號 |
  | 3 欄 | 獎項等級、內容、序號 |
  | 2 欄 | 內容、序號 |

  - 取得時間可寫 `09/16 19:49:52` 或 `2025/09/16 9:05`；沒寫年份時自動判斷是今年還是去年。
    儲存格裡日期和時間分兩行（Excel 複製出來會加雙引號）也能讀。
  - 格式不對的列會列出第幾筆、原因和原始內容，其他正確的列照常匯入。
- **重複序號不會重複新增**：不分大小寫比對（包含垃圾桶裡的），已存在的序號會略過並保留原本的狀態。

### 列表與狀態

- 每筆序號的狀態：**未兌換**、**已兌換**、**已送出**；效期過了且沒兌換的顯示 **已過期**。
  在設定的天數內到期的，效期變橘色並標「快到期」。
- 列表上可以直接操作：
  - 勾「已兌換」欄的勾選框 → 標為已兌換（記錄兌換時間），取消勾選就改回來。
  - 「送給誰」欄按「送出」→ 輸入名字；已送出的可以按「收回」。
  - 序號旁的按鈕一鍵複製序號。
  - 點備註欄直接編輯，Enter 存檔、Esc 取消。
  - 內容太長會截斷，點一下可以看完整內容。
- **搜尋與篩選**：用序號或內容搜尋；依狀態（全部／未兌換／快到期／已過期／已兌換／已送出）和獎項等級篩選。

### 多選批次操作

勾選多筆後，畫面底部會出現操作列：

- **狀態更新**：點開後選擇
  - 已兌換：勾選的全部標為已兌換（本來就是已兌換的不動）。
  - 送出：把勾選中「未兌換」的序號送給同一個人。
  - 改回未兌換：清掉兌換時間和送給誰（會先確認）。
- **更改效期**：勾選的全部改成同一個效期，不管狀態（會先確認）。
- **匯出 Excel**：存成 .xlsx，欄寬自動加寬，序號一律存成文字。
- **複製文字**：以 Tab 分隔複製到剪貼簿，可以直接貼回 Excel。
- **刪除**：移到垃圾桶（會先確認）。

### 垃圾桶

- 刪除的序號先放進垃圾桶，可以「復原」或「永久刪除」，也可以「清空垃圾桶」。
- 永久刪除前都會再確認一次。

### 到期通知

- 程式開著時（包含縮到系統匣），會定時檢查有沒有快到期的序號，跳出 Windows 通知。
- 點通知會打開視窗，並直接篩選出「快到期」的序號。

### 設定（左上角齒輪）

- **外觀**：主題（淺色／深色／跟隨 Windows），淺色和深色各自可以調色相和明暗；字型、字體大小（小／中／大）。
- **關閉視窗時**：收進系統匣（預設）或直接結束。收進系統匣後，從右下角圖示叫回或結束程式。
- **功能開關**：批次匯入、批次匯出、到期通知。關掉的功能整個隱藏。
- **欄位開關**：送出功能、獎項等級、取得時間（預設關）、備註。
- **數值設定**：快到期天數（預設 7 天）、通知檢查頻率（預設每 24 小時）。
- **備份／讀取**：把所有序號和設定備份成一個檔案；讀取時會**合併**進目前的資料（已存在的序號保留現在的狀態，不會被蓋掉）。

## 自己編譯

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download)。

```bash
# 開發時執行
dotnet run

# 打包成單一 exe（不需要另外安裝 .NET），輸出在 publish 資料夾
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```

技術：C# / .NET 10、WinForms + Blazor Hybrid（WebView2）、SQLite（Microsoft.Data.Sqlite）、ClosedXML。
